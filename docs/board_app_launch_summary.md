# MBC WalkWith App 项目与上线预算说明

Status: draft for board review

## 一、项目简介

MBC WalkWith 是一个面向教会会友和同工的移动 App 与后台管理系统。
它的目标不是做社交媒体，而是建立一个安静、可靠、可长期维护的教会生活工具。

App 帮助会友读经、听讲道、跟进教会生活、提交代祷、管理奉献记录和年度奉献证明。
后台帮助教会同工维护讲道、公告、活动、奉献记录、年度证明、财务对账和审计记录。

当前产品主干已经基本成型，整体完成度约 88%。剩余工作主要是正式上线前的生产配置：
服务器、域名、开发者账号、Stripe 生产环境、对象存储、年度证明正式文案和发布流程。

## 二、产品目标

### 短期目标

上线一个稳定可用的教会 App，让会友可以：

- 阅读圣经。
- 使用文字转语音朗读圣经。
- 听教会讲道。
- 查看教会公告、活动和生活内容。
- 提交和查看代祷事项。
- 通过 Stripe 安全奉献。
- 查看奉献历史和年度奉献证明。

### 中期目标

让教会同工可以自己维护内容，而不需要每次依赖开发人员：

- 上传讲道音频和讲章文案。
- 发布公告、活动和周报。
- 管理生活内容的草稿、审核和发布。
- 查看奉献交易和 Stripe 回调事件。
- 生成年度奉献证明。
- 做基础财务对账。

### 长期目标

形成教会自己的数字资料库和会友服务平台：

- 讲道档案。
- 经文与讲道关联。
- 教会生活通知。
- 代祷与关怀流程。
- 奉献记录和年度证明。
- 内容、财务、权限和审计记录。

## 三、当前功能范围

### App 端功能

面向会友和访客：

- 圣经阅读：支持多语言经文、本地阅读、章节跳转、继续阅读。
- 圣经朗读：使用 TTS 文字转语音朗读圣经，不使用有版权的音频圣经。
- 读经辅助：经文解释、人物/地点辅助、笔记、高亮、收藏。
- 讲道列表：查看讲道、讲道详情、文稿、大纲和经文引用。
- 讲道播放：播放教会上传的讲道音频，支持进度保存、速度调节和后台播放。
- 生活模块：查看教会公告、活动、周报和图片内容。
- 代祷模块：提交和查看代祷事项，并支持隐私和审核思路。
- 奉献入口：通过 Stripe Checkout 安全跳转奉献，App 不保存银行卡或银行账户信息。
- 奉献历史：查看已确认入账的奉献记录。
- 年度奉献证明：支持 CSV 预览、复制，PDF 保存、打开和系统分享。
- 会员中心：登录、通知偏好、主题、语言和读经辅助设置。

### 后台管理功能

面向教会同工、管理员和财务人员：

- 讲道管理：创建讲道、上传音频、上传/编辑文案、发布到 App。
- 生活内容管理：发布公告、活动、图片和可见性设置。
- 发布流程：支持草稿、审核、发布、归档。
- 奉献管理：查看交易、导出 CSV、生成年度证明。
- Stripe 事件追踪：查看 webhook 是否处理成功。
- 财务对账：查看总额、手续费、净额、退款、争议和 payout 状态。
- 权限与审计：财务、内容、管理员操作都有权限和审计基础。

## 四、奉献与 App Store 政策说明

本 App 的奉献功能不是数字商品购买，也不是 App 内订阅或内购。
它是会友对教会的自愿奉献。

因此建议采用：

- App 内显示奉献入口。
- 点击后跳转到 Stripe Checkout。
- Stripe 处理银行卡、ACH、Apple Pay 或 Google Pay。
- App 不接触、不保存任何银行卡或银行账户信息。
- 最终奉献状态只以后端收到并验证的 Stripe webhook 为准。

这条路径更适合教会奉献，也能避免把奉献误做成数字内购。

## 五、上线所需账号与资源

### Apple Developer Program

用途：发布 iOS App 到 App Store。

标准费用：99 美元/年。

Apple 对符合条件的非营利组织、教育机构和政府机构提供会员费减免。
如果教会符合条件并申请通过，Apple Developer Program 年费可以免除。

参考：

- https://developer.apple.com/programs/
- https://developer.apple.com/support/membership-fee-waiver/

### Google Play Console

用途：发布 Android App 到 Google Play。

费用：25 美元一次性注册费。

参考：

- https://support.google.com/googleplay/android-developer/answer/6112435

### Stripe

用途：处理奉献支付。

美国标准线上卡费率通常为 2.9% + 0.30 美元/笔。
Stripe 也有非营利组织优惠申请，通常需要提供 EIN、501(c)(3) 或 IRS 证明，并且交易主要来自免税捐赠。

参考：

- https://stripe.com/pricing
- https://support.stripe.com/questions/fee-discount-for-nonprofit-organizations

### 域名

用途：App API、后台管理、文件访问和正式品牌入口。

建议：

- 使用教会已有域名的子域名，例如 `app.examplechurch.org`、`api.examplechurch.org`。
- 或注册独立域名，例如 `mbcwalkwith.org`。

费用预估：约 12-25 美元/年，具体取决于域名后缀和注册商。

Cloudflare Registrar 按成本价销售域名，是一个可考虑选项。

参考：

- https://www.cloudflare.com/products/registrar/

### 服务器

用途：运行后端 API、后台管理、任务处理、文件上传接口等。

低成本方案：

- 一台 VPS 同时运行后端、后台和数据库。
- 费用约 12-24 美元/月。
- 优点是便宜。
- 缺点是数据库备份、升级、监控和故障恢复压力更高。

稳妥生产方案：

- 后端服务器：约 12-24 美元/月。
- 数据库使用托管服务，例如 Supabase Pro：约 25 美元/月起。
- 优点是数据库备份、监控和维护压力更小。

参考：

- https://www.digitalocean.com/products/droplets
- https://supabase.com/pricing

### 文件存储

用途：存储讲道音频、生活图片、年度证明 PDF、未来附件等。

建议使用 Cloudflare R2 或其他 S3 兼容对象存储。

Cloudflare R2 早期使用量很低时可能接近 0 美元/月。
后续费用主要按存储容量计算。

参考：

- https://developers.cloudflare.com/r2/pricing/

### 邮件与通知

用途：

- 会员通知。
- 年度证明提醒。
- 系统邮件。
- 后台告警。

早期可以先使用低成本或免费额度服务。
正式上线建议预留 0-20 美元/月。

## 八、上线前还需要完成的事项

### 教会需要提供

- Apple 开发者账号申请资料。
- Google Play 组织开发者账号资料。
- Stripe 组织账号资料。
- EIN、501(c)(3) 或 IRS 相关证明，用于申请 Stripe 非营利优惠和 Apple 年费减免。
- 正式域名或子域名。
- 年度奉献证明 PDF 的正式抬头、教会地址、EIN 和法律声明。

### 技术侧需要完成

- 生产服务器部署。
- 数据库和备份配置。
- 域名 DNS 和 HTTPS。
- Stripe 生产 webhook。
- Apple Pay / Google Pay 相关配置。
- App Store 和 Google Play 发布资料。
- 对象存储和签名下载。
- 上线前安全检查和测试。

## 九、建议决策

建议理事会批准以下方向：

1. 以免费 App 的方式上线，不设置数字商品内购。
2. 奉献通过 Stripe Checkout 处理，App 不保存任何支付信息。
3. 申请 Apple 非营利开发者费用减免。
4. 注册 Google Play Console 组织开发者账号。
5. 使用教会域名或子域名。
6. 初期采用稳妥生产方案，年度基础预算按 800-1,200 美元预留。
7. Stripe 手续费作为奉献处理成本单独核算，并申请非营利优惠。
8. 上线前由教会确认年度奉献证明 PDF 的正式文案。

## 十、结论

MBC WalkWith 不是一次性的宣传页面，而是教会长期使用的数字基础设施。

它可以帮助会友在日常生活中更容易读经、听讲道、了解教会生活、参与代祷和管理奉献证明。
它也可以帮助教会同工更稳定地发布内容、维护讲道资料、管理奉献记录和保留审计记录。

当前开发已经接近可上线状态。
下一步重点是生产部署、账号申请、域名配置、Stripe 生产环境和正式发布流程。
